# Puzzle Room and Scene Editor Guide

## Overview

- **`/puzzle`**: a WebXR princess room for Meta Quest 3. The princess appears inside a painting as a live video generated by Orbis. Players solve puzzles with hand gestures, and each solved puzzle can send Orbis a new instruction that changes what the princess does.
- **`/editor`**: a desktop scene editor used to lay out the room and attach puzzles to objects. The puzzle chain is defined in the scene data, not in code.

## Setup

```bash
git clone https://github.com/YMU7/Hero-Orbis.git
cd Hero-Orbis
pnpm install
```

Create `.env.local` next to `package.json` (see `.env.example`):

```
REACTOR_API_KEY=<key from the project owner>
```

`.env.local` is git-ignored. Do not commit it.

## Running locally

```bash
pnpm dev
```

| URL | Purpose |
|---|---|
| `http://localhost:3000/editor?scene=puzzle` | Scene editor (development mode only) |
| `http://localhost:3000/puzzle?mode=mock` | Play the room with a placeholder video (no Orbis credits) |
| `http://localhost:3000/puzzle?mode=live` | Play the room with live Orbis (uses credits) |

In a production build, `/editor` returns 404 and scene saving is disabled unless `ENABLE_SCENE_EDITOR=1` is set.

## Editing the room

| Input | Action |
|---|---|
| Left mouse drag | Orbit |
| Right mouse drag | Pan |
| Mouse wheel | Zoom |
| Click | Select an object |
| W / E / R | Move / rotate / scale gizmo |
| F | Focus the selected object |
| Ctrl+D | Duplicate |
| Delete | Delete |
| Ctrl+S | Save now |

- **Room pieces** adds built-in furniture.
- **Import GLB / GLTF** adds your own models.
- The painting, easel, gramophone and button pedestal are required. They can be moved but not deleted or duplicated.
- Changes are saved automatically to `data/scenes/puzzle.json`. Refresh `/puzzle` to see them.

## Adding a puzzle

1. Select an object.
2. In the Inspector, click **+ Puzzle**.
3. Fill in the fields:

| Field | Description |
|---|---|
| **ID** | Short unique name, for example `vase`. Other puzzles refer to it in **Requires**. |
| **Trigger** | How the player solves it. Gramophone: put the needle on the record. Easel: draw a sword on the canvas. Other objects: touch or pinch. On desktop, a mouse click counts as touch or pinch. |
| **Requires** | A puzzle that must be solved first. This sets the order. |
| **When solved, send to Orbis** | What the princess does once the puzzle is solved, for example: "She claps and smiles at you." Leave empty to send nothing. |
| **Audio prompt** | Optional. What the generated audio should sound like. |
| **Sound** | Sound effect played in the room when the puzzle is solved. |
| **Hint** | Text shown in the room while this is the next puzzle, and when the player tries a puzzle that requires this one. |

The easel's puzzle also has **Sword recognition thresholds** for tuning how strict the drawing check is.

To change what the princess does when she first appears, select the **painting** and edit **When she appears**.

### Writing instructions

- Describe actions only.
- The art style, character look, painting background and camera are fixed and always sent before your instruction. Do not describe style, colours, lighting, camera or outfits. The editor shows a warning when an instruction contains words that are likely to change the look.
- Do not use names of games, films, series or characters.

### Hierarchy indicators

- **puzzle** tag: the object has a puzzle.
- Red warnings: a **Requires** that points to a missing puzzle, or a loop of requirements.

## How puzzles behave at runtime

- A puzzle can be solved only after its **Requires** puzzle is solved. An early attempt shows the hint of the puzzle that is blocking it.
- Needle-on-record and sword-on-canvas are states. If the player completes one before its requirement, it counts automatically once the requirement is solved. Touch and pinch must be repeated after the requirement is solved.
- Each solved puzzle that has an instruction sends one new prompt to Orbis. After a reconnect, the princess continues with the last instruction.
- **Reset puzzle** clears all progress and returns to the opening instruction.

## Testing

### Desktop (mock)

Open `/puzzle?mode=mock`.

- Click the gramophone to drop or lift the needle.
- Drag on the easel canvas to draw.
- Click objects to touch or pinch them.
- Use the arrow keys to look around.
- The side panel lists each puzzle as `solved`, `open` or `locked`, and shows what the princess is currently doing.

### Live Orbis

Open `/puzzle?mode=live` and press **Connect**. Press **Disconnect** when finished, because a live session uses credits.

### Meta Quest 3

WebXR requires HTTPS on the headset. Either:

- use a tunnel URL provided by the project owner, or
- run `pnpm dev:https` and open the computer's LAN address on the headset.

Press **Enter VR**. With hand tracking:

- pinch to pick up the crayon or the gramophone tonearm;
- touch buttons and puzzle objects with a fingertip.

## Audio

The room has four channels: background, objects (the gramophone, positioned in 3D), interaction sound effects, and the princess voice from Orbis. Volumes are under **Room audio** in the editor.

Built-in synthesized sounds are used by default. To use a recording instead, put a file named after the sound ID in `data/puzzle-audio/` (`.mp3`, `.ogg`, `.wav` or `.m4a`), then refresh `/puzzle`.

Sound IDs: `background`, `gramophone`, `crayon-pick`, `crayon-drop`, `crayon-draw`, `button`, `needle-down`, `needle-up`, `tonearm-grab`, `sword-right`, `sword-wrong`, `puzzle-solved`.

## Workflow

1. Run `git pull` before starting.
2. Make changes and test them in mock mode.
3. Commit and push small changes often.
4. The whole room layout and every puzzle live in one file, `data/scenes/puzzle.json`. Only one person should edit the room at a time. Tell the team before you start, and push as soon as you finish.
5. Do not commit `.env.local` or `*.bak` files.

## Files

| Path | Contents |
|---|---|
| `data/scenes/puzzle.json` | Room layout and puzzle components |

| `app/puzzle/` | Puzzle room runtime |
| `app/lib/sceneData/` | Scene data types, validation and storage |
